HAMKEE

Zero-Width Steganography

Hide a short message inside ordinary text using invisible Unicode characters. Everything runs in your browser; nothing is sent anywhere.

This is not encryption. Anyone with this tool (and the passphrase, if you set one) can read the message, and software that looks for invisible characters can detect or remove them.

Room for the message

Paste a carrier text to see how much it can hold.

Deletes every invisible character this tool uses and gives back the plain visible text, for example to clean a text before you forward or publish it, or to get the original carrier back. It does not read the message (use Decode for that). Note: the same invisible characters are also used legitimately, for example as left-to-right or right-to-left marks in mixed-script text, and those are removed too.
